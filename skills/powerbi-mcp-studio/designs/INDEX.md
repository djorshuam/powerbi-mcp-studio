# Galeria de design (DESIGN.md)

Analises de linguagem visual de sites conhecidos, no formato DESIGN.md (Google Stitch). Use como **inspiracao** ou ponto de partida para o DESIGN.md do cliente — nao para reproduzir a marca de terceiros num entregavel. Fonte: VoltAgent/awesome-design-md (MIT, ver `LICENSE-awesome-design-md.txt`).

Coluna **Tokens**: `sim` = tem cabecalho YAML com cores/tipografia; o `scripts/tema_pbi.py` gera o tema do Power BI direto dele. `nao` = so texto; o Claude le e escreve os tokens (ver `references/design-tema.md`).
