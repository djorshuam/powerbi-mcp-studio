# Segurança

Os scripts rodam localmente e só alteram os arquivos indicados, sempre com backup. Nenhum dado é enviado para fora da máquina pelos scripts (a integração com o Figma usa o seu token, guardado no `.env` local, que está no `.gitignore`).

Encontrou uma vulnerabilidade? Abra uma issue sem detalhes sensíveis ou contate o mantenedor pelo perfil do GitHub.
